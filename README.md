SWYNEX - Interactive Sales Dashboard

Project Overview

This project presents an interactive sales dashboard created using Microsoft Power BI. It analyzes retail sales data to understand sales performance, customer activity, and product trends.

Objectives

- Monitor key sales performance indicators.
- Analyze monthly revenue and transaction trends.
- Identify top-selling products by revenue and quantity.
- Explore sales performance across countries.
- Present useful insights through an interactive dashboard.

Tools Used

- Microsoft Power BI
- DAX
- Data visualization
- Retail sales dataset

Dashboard Features

- Total Revenue
- Total Transactions
- Total Customers
- Total Quantity
- Average Order Value
- Monthly Revenue Trend
- Monthly Transactions Trend
- Top 10 Products by Revenue
- Top 10 Products by Quantity
- Country and Invoice Date filters
- Key Insights section

Key Findings

- The United Kingdom generated the highest revenue.
- November 2011 was the highest-revenue month.
- Product sales varied, with some products contributing strongly to revenue.
- Negative-quantity transactions highlight the importance of examining returns and cancellations.
